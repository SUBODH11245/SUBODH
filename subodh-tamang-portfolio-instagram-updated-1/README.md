# Subodh Tamang — Personal Portfolio

A responsive, dark cinematic personal portfolio built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — styling, responsive layout and animations
- `script.js` — mobile menu, scroll reveals, active navigation and progress bar

## Publish with GitHub Pages
1. Create a **public** GitHub repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css` and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Visit `https://YOUR-USERNAME.github.io` after GitHub finishes publishing.

## Personalize before publishing
- Contact email and phone number are already set in the Contact section. Update them in `index.html` if they change.
- Update the About, Interests and Projects text whenever you want.
- The Socials section includes Instagram, Discord, GitHub and YouTube placeholders. Replace each placeholder with your own profile URL/username before publishing.

The Google Fonts import requires an internet connection. The page still works if the fonts cannot load, using system fallbacks.
